# Frontend Module Map

## Safety Rule

All frontend work in this repository targets `yasnaproject`. The old `yasnanegotiations` production backend, Pages URL, GitHub repo URL, Firebase realtime, and Telegram bot remain quarantined.

## Runtime Pages

| Page | Main file | Preview copy | Current role |
| --- | --- | --- | --- |
| Main app | `docs/index.html` | `docs/preview/index.html` | Star diagram, lessons, tours, local tools |
| Duel v1 | `docs/duel.html` | `docs/preview/duel.html` | Current playable duel shell |
| Duel v2 | `docs/games/duel/v2/duel.html` | `docs/preview/games/duel/v2/duel.html` | Content-tree experiment, still quarantine |
| Admin | `docs/admin.html` | `docs/preview/admin.html` | Local content editing; publishing disabled |
| Status | `docs/environment-status.html` | none | Public quarantine/isolation status |

## Shared Contracts

| Contract | Files | Notes |
| --- | --- | --- |
| Environment | `docs/core/env.js`, `docs/preview/core/env.js` | Owns `window.YasnaEnv`; API/bot stay empty in quarantine |
| Theme | `docs/core/theme.js`, `docs/preview/core/theme.js` | Owns `window.YasnaTheme`; bridges light/dark and legacy class |
| Design tokens | `docs/design-system.css`, `docs/preview/design-system.css` | Owns `--ys-*` tokens and shared primitives |
| Content merge | `docs/core/content-store.js`, `docs/preview/core/content-store.js` | Tier-1 bundle plus Tier-2 local overrides |
| Build bundles | `docs/dist/*`, `docs/preview/dist/*` | Generated by `npm run build`; do not hand-edit |

## Refactor Boundaries

Safe next refactors:

- Move repeated theme-toggle behavior into `core/theme.js` only.
- Convert touched CSS from hardcoded colors to `--ys-*` tokens.
- Add tests around public globals: `YasnaEnv`, `YasnaTheme`, `YasnaContentStore`.
- Keep preview files synchronized for critical shared contracts.

Quarantined until new resources exist:

- `server/*` deployment activation.
- Firebase realtime and `rt-firebase.js` initialization.
- Telegram auth for a real bot.
- Leaderboard submit/fetch endpoints.
- Admin publishing.

## Duplication Policy

`docs/preview/` remains a mirror while the project is static Pages-based. To reduce accidental drift, critical contracts are checked by `npm run check:preview-sync`. Wider removal of preview duplication should wait until a routing/build decision is made, because deleting the mirror can change public URLs.

## Required Checks Before Push

- `npm run check:safety`
- `npm run build`
- `npm test`
- `git diff --check`
